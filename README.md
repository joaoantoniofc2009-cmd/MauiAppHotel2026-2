# Aurora Hotel — Projeto .NET MAUI

Projeto acadêmico de hotelaria desenvolvido com .NET MAUI e C#.

## Funcionalidades
- Seleção da quantidade de adultos e crianças.
- Seleção de acomodação.
- Seleção das datas de check-in e check-out.
- Validação das datas e cálculo demonstrativo do valor da estadia.
- Tela de resumo da solicitação.
- Tela Sobre com informações do projeto e do desenvolvedor.

## Observação
Os preços das acomodações são valores ilustrativos definidos para demonstrar o cálculo no aplicativo. O projeto não realiza reservas reais nem se conecta a um sistema hoteleiro.

## Tecnologias
- C#
- .NET MAUI
- XAML
